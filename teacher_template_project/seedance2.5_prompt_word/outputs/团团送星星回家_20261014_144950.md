# 《团团送星星回家》Seedance 2.5 提示词

## 项目概况

- 类型：温暖奇幻轻喜剧、萌宠微短剧
- 原始剧本时长：约 3 分钟
- 输出方式：拆分为 7 个连续片段，每段不超过 30 秒
- 画幅：16:9 横屏（剧本指定）
- 模式：文生视频
- 音频：需要环境声、对白、动作音效和温暖音乐
- 参考素材：未提供

## 统一连续性设定

小满是居住在房间里的年轻女孩，外观、发型和服装在所有片段中保持一致；团团是小满的陪伴犬，体型、毛色和外观保持一致。场景始终是夜晚的小满房间，房间里有几个纸箱、书本、窗户、窗帘和普通月光。星星是一颗小巧的立体星星，最初微微发亮，之后可以发出柔和星光；它的亮度、位置和运动方向必须连续。整体风格为写实电影感、温暖、克制、轻微奇幻，动作自然，表演细腻，避免突然改变人物、狗、房间和道具外观。除剧本对白外，不添加旁白、字幕、Logo 或屏幕文字。

```text
温暖写实的奇幻电影感短片，夜晚的小满房间，房间里堆着几个纸箱和书本。小满是外观连续的年轻女孩，团团是外观连续的陪伴犬，星星是一颗小巧、微微发亮的立体星星。保持人物、狗、房间和道具位置连续，16:9 横屏。

[8–16秒] 全景低机位，团团从门口跑进来，嘴里叼着一颗微微发亮的小星星，由画面左侧跑向右侧，停在小满脚边。镜头短暂跟移，保留狗爪踩地声，加入轻微奇幻音效。

[16–22秒] 中近景平视，团团把星星放到小满脚边，低头闻星星，小满身体前倾看向它。小满说：“这是什么？你从哪儿捡来的？”保留闻嗅声，星星位于小满脚边中央。

[22–28秒] 星星忽然开始变亮，柔和的光映在小满和团团脸上，墙壁和地板出现稀疏星点。镜头从星星轻轻推近，音乐加入温暖的奇幻色彩。
```

### 衔接说明
