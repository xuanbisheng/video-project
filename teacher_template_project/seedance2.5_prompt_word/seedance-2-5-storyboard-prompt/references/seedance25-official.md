# Seedance 2.5 官方资料要点

来源：字节跳动 Seed 官方产品页《Seedance 2.5》：<https://seed.bytedance.com/zh/seedance2_5>

本参考只记录页面明确展示的能力，用于生成提示词时确定边界；页面中的示例文案是能力演示，不是必须套用的固定模板。

## 可据此使用的能力

- 页面定位 Seedance 2.5 为“具备 30 秒长叙事、精准参考与编辑能力”的音视频生成模型。
- “更长叙事，更稳掌控”模块明确写出：单段视频时长提升至 30 秒，并支持两次视频延长；运动效果更稳定、画面真实感更强。
- “精细化参考与编辑”模块说明模型更好理解参考视频的意图与镜头语言，覆盖更多音视频编辑场景。
- “为专业视频创作而生”模块明确提到白模控制、绿幕编辑，以及专业运镜与表演调度。
- 官方示例展示了文本生成视频、参考图片/视频生成、音频编辑、视频编辑、多镜头连续动作、对白、旁白和环境声等提示词写法。示例中会用 `@图片1`、`@视频1`、`@音频1` 一类引用标签说明素材角色。

## 生成时的边界

- “单段最多 30 秒”是本技能的交付上限；超过时长应拆分成连续片段。官方页面提到可延长两次，但没有在该页面给出 API 字段、分辨率枚举、帧率枚举或固定提示词语法，因此本技能不虚构这些参数。
- 参考素材标签只有在用户提供或明确指向素材时才保留；标签不等于可访问的文件或 URL。
- 画幅、镜头节奏、对白语言、音频内容等属于用户创作要求。未指定时可以给出清晰的默认设定，但要标注为默认，而不是声称官方强制。
