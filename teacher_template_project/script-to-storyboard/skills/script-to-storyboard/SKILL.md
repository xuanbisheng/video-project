# Script to Storyboard

把已确认的影视剧本转换为可执行的逐镜头文本分镜。分镜可以重组视觉呈现，但必须保持人物身份与关系、事件顺序、关键行为和对白含义、关键道具、冲突结果、角色已掌握的信息以及已锁定的世界规则。

## 输入门槛

开始前读取并确认：

- 剧本正文（必须存在；缺失时先要求剧本，不直接制作分镜）。
- 项目类型、目标画幅、目标总时长或单场时长。
- 视觉风格和节奏倾向、制作限制（场景、演员、设备、特效、预算）。
- 详细程度（简洁、标准、详细）；未指定时使用标准模式。
- 必须保留以及禁止增加、删除或修改的对白、动作和剧情事实。
- 是否允许提出可视化调整建议。

若画幅、时长或载体缺失且会影响镜头设计，最多提出三个关键问题。用户允许自由决定时，采用合理默认值，并在输出前用一句话说明假设。

## 三种输出模式

- **简洁**：镜号、画面内容、景别、镜头运动、对白/声音、预计时长。
- **标准**（默认）：完整分镜表，包含剧本锚点、时长、景别/角度、画面与动作、人物调度/表演、镜头运动、对白/声音、剪辑/连续性。
- **详细**：标准模式再加设计意图、构图重点、焦点变化、光线提示、剪辑衔接、连续性要求和制作难点。

用户要求“只输出分镜表”时，省略分析过程、解释和待确认事项以外的额外文字。

## 转换流程

1. **解析场景**：为每场记录场次、内外景、地点、时间、人物、场景任务、核心冲突、动作/对白节点、信息揭示、情绪转折、场景结果和与下一场的衔接；不得漏掉推动剧情的动作、对白或反应。
2. **建立锚点**：给关键节拍编号，例如 `S01-B01`、`S01-B02`。沿用剧本已有编号。每个镜头至少关联一个锚点，便于追踪遗漏、重复、顺序变化和无依据新增。
3. **划分视觉节拍**：当关注对象、重要信息、人物目标/策略、情绪、空间位置、动作阶段、叙事视角或剪辑节奏发生变化时考虑切镜。不要机械地一句对白切一个镜头；每镜只承担一个主要视觉任务。
4. **设计镜头**：确定镜号、锚点、时长、景别/机位角度、构图主体、开始状态、主要动作、结束状态、走位/表演、镜头运动、声音、剪辑关系和连续性要求。镜头至少服务于建立空间、呈现动作、强调关系、揭示信息、表达情绪、制造悬念、控制节奏或完成转场中的一项。避免无目的的航拍、环绕、推拉摇移、倾斜构图或复杂长镜头。
5. **对白场景**：先固定空间位置、视线、轴线、主导关系和信息顺序，再选择双人、正反打、过肩、单人近景、反应或插入。用停顿、反应和动作表达情绪；未经允许不得删改或重新分配关键对白。
6. **动作场景**：先建立空间，再交代人物目标、危险来源、动作过程和结果。保持动作方向、位置、道具和伤势在相邻镜头间连续，避免“快速切换”“激烈打斗”等不可执行的空泛描述。
7. **适配画幅**：只在用户给出画幅后启用对应规则。9:16优先保证面部、手部和关键道具在有效区域，明确多人视觉中心，不能把所有镜头都变成近景；宽银幕可利用横向距离与环境，但关键主体不能无目的地落在边缘。详见 [references/storyboard-format-guide.md](references/storyboard-format-guide.md)。
8. **估算时长**：为每镜、每场和全片计算时长，考虑实际朗读、停顿、动作完成、运镜和理解时间，另列对白、动作和转场耗时。超出目标时，先指出超时位置，再建议合并功能重复镜头、缩短无效停顿、减少重复反应或简化不影响剧情的调度，不直接删除剧情。

## 输出结构

按下列结构输出，除非用户指定其他格式：

1. **项目信息**：项目名称、剧本范围、载体、画幅、目标时长、分镜模式、视觉/节奏假设。
2. **场景概览**：场次、地点与时间、出场人物、场景任务、情绪变化、预计时长。
3. **分镜脚本**：标准列为 `镜号｜剧本锚点｜时长｜景别/角度｜画面与动作｜人物调度/表演｜镜头运动｜对白/声音｜剪辑/连续性`。画面与动作必须写清镜头开始看见什么、发生什么、结束停在哪里。
4. **场景连续性**：人物位置、视线与轴线、动作方向、道具状态、服装/妆容、光线/时间、上一场承接、下一场衔接。
5. **时长汇总**：镜头数量、场景预计时长、总预计时长、与目标时长差异。
6. **待确认事项**：只列会影响执行且确实需要用户决定的问题；没有则省略。

## 连续性与忠实度门禁

交付前逐项检查并先修正问题：

- 每个重要剧情节拍都有镜头且每镜可追溯到锚点；无遗漏、重复或顺序错误。
- 镜号唯一且顺序连续；每镜有明确视觉任务，景别变化和运镜服务于信息、情绪或节奏。
- 进出画方向、视线关系、轴线、动作方向、人物位置和动作衔接连续；有意越轴须说明叙事目的或过渡镜头。
- 道具持有者、位置和状态，人物坐立、伤势、衣着、妆容和情绪连续；同场时间、光线和关键声音来源合理。
- 对白、动作和反应匹配，画幅和制作限制得到遵守，镜头时长之和接近目标。
- 未擅自改变人物、关系、事件顺序、关键行为/对白含义、道具、冲突结果、角色信息或世界规则。

无法直接视觉化的内容，单独标为“可视化建议”，与正式分镜分开；未经用户确认不得把建议写成既定剧情。不要生成分镜图片、绘画/Midjourney/视频模型提示词、拍摄计划、通告单、预算表或剧本评价。
