# 分集剧本输出格式

默认采用以下结构。用户指定其他格式时，以用户格式为准，但仍保留可拍摄性、连续性和锁定事实要求。

## 集级信息

```text
第X集：标题
预计时长：
本集目标：
核心冲突：
本集结果：
集尾钩子：
```

## 正文

每个场次使用统一标题：

```text
场次1｜内景/外景｜地点｜日/夜
出场人物：人物姓名、人物姓名
动作和环境描述。

人物A：（必要且可表演的动作或语气）对白。
人物B：对白。
```

场景描述只写能被拍摄或表演的内容。若有关键道具、声音、视线、停顿或动作，应在动作和环境描述中明确写出。连续场次按同样格式编号。

## 本集状态变化

```text
人物状态变化：
关系变化：
新增信息：
已兑现伏笔：
新增伏笔：
下一集承接压力：
```

只填写本集实际发生或明确建立的变化；没有内容时写“无”，不要为了完整而虚构信息。

## 正文模式

当用户要求只输出剧本正文时，从“场次1”开始输出连续场次，省略集级信息、本集状态变化、分析过程和质量检查。
