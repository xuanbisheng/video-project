# 剧本载体格式指南

本文件只描述不同载体的排版和媒介特有信息。通用的事实管理、场景因果、对白和质量要求见上级 `SKILL.md`。确定载体后只读取对应章节。

## 影视剧本（电影、剧情短片、品牌剧情片）

### 必备格式

- 场次编号
- 内景/外景（INT./EXT. 或中文）
- 地点
- 时间
- 出场人物（可在首次出现时列出）
- 动作描述
- 人物名与对白
- 确有必要的表演提示

### 简短示例

```text
1. 外景｜旧车站｜黄昏

林岚拖着箱子走到检票口。闸机亮起红灯。

林岚
（压低声音）
你还要拦我多久？

检票员看向她手里的旧车票，没有回答。
```

默认不写镜号、景别、运镜、剪辑指令或其他详细镜头语言，除非用户明确要求。

## 电视剧与短剧/微短剧

在影视剧本格式上增加结构信息：

- 集数与标题
- 本集目标与本集结果
- 与上一集的承接
- 与下一集的衔接

只有用户明确选择短剧形式，并提供或要求平台、单集时长和节奏目标时，才考虑开场钩子、局部爽点、集尾悬念或付费卡点。

### 简短示例

```text
第3集《回声》
本集目标：林岚拿到录音。
本集结果：录音被公开，真正的录制者暴露。

1. 内景｜直播间｜夜
...
```

## 舞台剧

使用幕和场组织文本，标明舞台空间、人物出场/退场、可执行的舞台动作，以及必要的灯光、音乐和音效提示。舞台提示要考虑现场表演和空间转换，避免依赖不可实现的镜头切换。

### 简短示例

```text
第一幕 第一场
空旷客厅。一扇门，一张桌子。

（灯光亮起。周宁站在门边，手里攥着信。）

周宁
他答应今晚回来。

（门外传来三声敲门。周宁退后一步。）
```

## 广播剧与有声剧

使用场景说明、人物名、对白、旁白、音效提示、音乐提示，并在必要时标明声音远近、方向或环境变化。观众看不见动作，关键行动和信息必须自然地通过声音、对白、反应或环境音传达；不要写只能靠画面理解的内容。

### 简短示例

```text
【场景：暴雨中的公交站。雨声近，偶有车辆驶过。】

旁白
站牌上的末班时间被雨水冲得模糊。

（脚步声由远及近，停在伞下。）

阿诚（左侧，喘息）
你一直在等我？

小满
我在等那班不会再来的车。
```
