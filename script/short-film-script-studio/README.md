# 短片剧本工作台

这是一个无需后端的本地网页界面，用来管理短片剧本从题材搜索到最终稿的确认流程。

## 功能

- 题材研究 Agent：先输入一个创意、类型、目标平台和市场，调用 Agent 搜索相近题材并产出 3 个故事简介；
- 题材反馈：候选题材、热度/偏好/短片适配度和来源记录；
- 故事方案：多个方案卡片、选中方案和修改信息；
- 故事成稿：完整故事正文、人物关系、规则、节拍、反转和 AI 制作建议；
- 剧本初稿：正文编辑和按场次卡生成骨架；
- 剧本审查：A/B/C 级问题、位置、建议和处理勾选；
- 最终剧本：载入初稿、修改和项目交付检查；
- 项目确认节点、操作记录、本地保存、示例项目和 Markdown 导出。

故事成稿是剧本前唯一的故事依据，已合并人物正典和结构规划职责；工作台不再提供独立的设定或结构阶段。

## 启动

最简单的方式是在本目录启动静态服务器：

PowerShell：

    python -m http.server 8080

然后打开：

    http://127.0.0.1:8080

也可以直接双击 index.html 打开，但部分浏览器可能限制本地文件的剪贴板或下载行为，推荐使用静态服务器。

## 与 Agent / Skill 配合

右侧的“下一步交接提示词”会根据当前阶段生成下一步指令，例如：

    使用 $story-drafting 根据已选方案生成 03_story.md；确认故事后，再使用 $screenplay-writing 创作完整短片剧本。

操作建议：

1. 在题材研究 Agent 中填写你的创意、类型、目标平台和市场；
2. 点击“确认条件并调用 Agent”；
3. Agent 搜索相近题材并返回研究依据和恰好 3 个故事简介；
4. 将 Agent 返回内容粘贴到页面，载入并比较 3 个方案；
5. 如果 3 个方案都不合适，在故事方案阶段点击“重新生成 3 个故事简介”；
6. 选定一个方案后，使用“故事成稿”阶段写完整故事；确认故事后进入剧本初稿、审查和最终稿。

## 数据说明

项目数据默认保存在当前浏览器的 localStorage 中。输入过程不会触发编辑区重绘，避免光标跳动和内容丢失。导出按钮会生成一个合并后的 Markdown 文件，不会自动上传数据，也不需要后端服务。

## 目录

- index.html：页面结构；
- styles.css：界面样式；
- app.js：阶段数据、交互、保存、导出和确认逻辑；
- SHORT_FILM_SCRIPT_PIPELINE.md：项目级 Agent 路由协议，位于上级目录。
