# 《再来一次，我就洗澡》3 分钟分场大纲

## 故事承诺与结构策略

- **故事承诺**：一只怕洗澡的猫用“三秒回溯”连续逃跑，主人逐渐识破规则并改变护理方式；观众得到重复动作笑点、规则升级和一个带余味的二次试探。
- **结构策略**：六场、单一住宅动线；前 60 秒快速建立规则，中段让主人获得同等信息，后段把“追捕”改成“协商”，用一次短暂和解和一次按钮试探收尾。
- **AI 视频策略**：每场由 5—8 秒镜头组成；重复使用猫的三个固定动作（回头、扑向按钮、缩回猫窝），通过剪辑制造循环，不依赖长镜头连续表演。
- **目标观众反应**：先笑猫太聪明，再笑主人终于发现规律，最后觉得猫和主人已经形成默契。

## 人物弧光检查点

- 团团：恐惧洗澡 → 发现漏洞 → 过度使用漏洞 → 看见主人降低刺激 → 主动暂时合作。
- 主人：直接追捕 → 误以为猫瞬移 → 识破回溯 → 放弃强制 → 用奖励和替代方案建立信任。
- 关系：护理冲突 → 互相利用规则 → 共同触碰按钮 → 形成新的默契。

## 连续性依赖和制作风险

- 回溯前后必须保持矮柜、浴巾、鱼干罐和扫地机器人的位置；每次只改变一个动作，观众才能读懂倒退。
- 需要制作一个固定外观的三秒回溯器：黑色圆角小盒、蓝色灯环、红色过热灯。
- AI 生成不稳定的中文 UI 全部用后期字幕解决；画面只保留灯色和提示音。
- 洗澡不拍猫被强行放入水中，改为温毛巾擦拭，降低动物表演和内容风险。
- 六次触发上限是叙事硬规则，剪辑中必须清楚显示蓝灯逐渐变红，避免结尾像突然失效。

## 需要用户确认的未决选择

1. **结尾护理方式**：A. 温毛巾擦拭 + 晒太阳（推荐，成本低、冲突柔和）；B. 只洗爪子（更贴近“洗澡”主题，但需要水面连续性）。
2. **对白比例**：A. 主人仅说两句，主要靠动作和字幕（推荐）；B. 增加主人吐槽旁白，喜剧更口语化。
3. **回溯次数**：A. 六次上限并显示过热（推荐）；B. 不设上限，改用主人识破后主动谈判。
