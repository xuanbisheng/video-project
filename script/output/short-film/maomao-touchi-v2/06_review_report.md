# 《再来一次，我就洗澡》剧本审查报告（v2）

## 总体结论

初稿已经具备清楚的主角目标、有限资源、两次反转和可执行的 AI 制作规模。没有发现会让故事完全失效的 A 级问题；有 3 个 B 级问题需要在终稿中处理，另有 2 个 C 级问题可用最小改动收紧。审查置信度：中高。

## 问题清单

### B1：手机倒计时的回溯含义可能被误读

- 位置：第 2 场“手机倒计时也回到 03:03”。
- 实际问题：手机属于客厅物件，画面回到 03:03 会让观众以为整个世界时间都倒退，进而追问直播截止时间为何没有真正推进。
- 影响：会稀释“只回溯客厅三秒”的规则，增加不必要的世界观解释。
- 修复方向：保留倒计时作为开场压力，但回溯时只表现浴巾、猫和鱼干碎屑归位；不要再次强调手机数字被重置，或把倒计时改成不显示具体秒数的拍摄提示灯。

### B2：水盆危机的触发需要更早的空间铺垫

- 位置：第 5 场“小林脚边的水盆被轻轻勾到”。
- 实际问题：水盆在高潮才被踢动，虽然因果成立，但观众可能把它看成编剧临时制造的救场机会。
- 影响：最后一次回溯从“选择”变成“被迫做正确的事”，削弱猫的主动性。
- 修复方向：第一场就交代水盆放在小林脚边、手机支架旁；高潮时让小林后退避开团团而碰到同一位置，重复空间关系即可。

### B3：循环段落的字幕与动作仍有一处同义重复

- 位置：第 3 场“浴巾回溯—鱼干回溯”之间的多条字幕。
- 实际问题：动作已经说明猫会重来，字幕仍连续重复同一承诺。
- 影响：占用约 6—8 秒，降低中点反转抵达速度。
- 修复方向：保留浴巾和鱼干两个不同功能的尝试，扫地机器人只用一个经过画面边缘的声音或半圈运动带出，并删掉一条重复字幕。

### C1：小林的一句解释对白可以更像反应

- 位置：第 4 场“不是跑得快，是重拍得快”。
- 实际问题：台词本身有笑点，但解释了观众已经从重复动作看懂的规则。
- 影响：轻微降低人物反应的自然度。
- 修复方向：缩为“你在重拍？”或干脆只让小林收手、把浴巾放下，用动作完成识破。

### C2：结尾字幕与片名的关系可以更直接

- 位置：第 7 场“这次是真的洗澡”。
- 实际问题：字幕回收了结果，但没有再利用猫一直重复的拖延句式。
- 影响：片名记忆点略弱，不过不影响故事成立。
- 修复方向：把结尾字幕改成“再来一次……这次真的洗澡”，既保留嘴硬，也不增加对白。

## 值得保留的优点

- 回溯器四格电量、颜色和声音构成清楚的视觉规则。
- 鱼干不会复制，避免了上一版最容易被误读的连续性问题。
- 小林通过共同触碰设备获得记忆，反转有前置动作而不是突然解释。
- 最后一次回溯用于水盆危机，让猫以主动行为改变关系，而不是被主人说服。
- 温毛巾替代浸水，符合宠物喜剧的内容边界和 AI 生成稳定性。

## 最小修改路径

按 A+B 范围处理 B1、B2、B3，并顺手处理 C1、C2：

1. 删除回溯后手机数字归位的描写，保留开场倒计时。
2. 在第一场交代水盆、手机支架与小林脚边的固定关系，高潮重复该空间。
3. 将完整循环压成浴巾一次、鱼干一次，扫地机器人只做声音/边缘干扰，并减少一条字幕。
4. 将识破对白压短，结尾字幕回收片名句式。

## 仍然存在的不确定性

- AI 模型是否能在多次固定构图中保持团团左耳深色毛和绿色项圈，需要先做角色参考测试。
- 水盆倾斜的动作可能出现液体形变，建议用“盆沿移动 + 水面轻晃 + 声音”三段素材剪接，而不是生成完整倾倒。
- 直播倒计时是戏剧压力而非外部世界规则；终稿将不再让手机数字参与回溯，以免扩大解释范围。
