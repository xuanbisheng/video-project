# 视频题材趋势研究

当用户要求研究当前热门视频题材、用户喜爱的内容形态、基于趋势寻找短片方向，或要求生成题材研究 Markdown 报告时使用本 Skill。本 Skill 只负责研究和综合，不负责直接写完整剧本。

## 输入信息

如果缺失的信息会明显改变结论，应先询问用户。通常需要：

- 目标平台和地区/市场；
- 语言和目标观众；
- 时间窗口（默认最近 90 天，并必须写出具体起止日期）；
- 题材、类型、基调和排除项；
- 希望输出的题材数量和文件路径。

如果用户没有指定平台或市场，要在报告中明确写出默认假设。不要把某个平台或地区的趋势描述成全球普遍趋势。

## 研究流程

1. 搜索当前、可靠、公开的来源。优先使用平台趋势页、创作者或行业报告、可信的数据分析报道和官方公告。每条重要结论都记录发布日期、观察日期、平台、市场和来源链接。
2. 为每个候选题材采集多种信号，并区分：
   - 热度信号：播放量、搜索热度、榜单、增长速度、重复出现频率或官方趋势标签；
   - 偏好信号：点赞、评论、分享、收藏、公开可见的完播/留存数据，以及评论中反复出现的积极反馈。
3. 重要结论至少使用两种独立信号交叉验证；无法验证时明确标注低置信度。不得编造不存在的播放量、情绪分析、留存率或排名。
4. 将单条视频聚合成题材模式。不能复制具体视频的剧情、人物、标题、对白或独特表达，只提炼受众需求、冲突模式、内容形式和情绪承诺。
5. 使用高/中/低的透明等级评价热度、用户偏好、持续性、短片适配度、原创空间和制作风险，并解释评分依据与不确定性。
6. 输出适合原创短片开发的方向，说明为什么值得做、哪些部分已经过度饱和，以及仍然存在什么切入空间。

## 输出格式

生成 Markdown 文档，至少包含以下部分：

1. 视频题材趋势研究标题；
2. 研究范围和结论日期；
3. 执行摘要；
4. 热门题材总览表，包含热度、用户偏好、持续性、短片适配度、原创空间和证据；
5. 每个重点题材的详细分析；
6. 推荐的原创短片方向；
7. 不建议直接跟风的方向；
8. 数据局限与置信度；
9. 来源与检索记录。

必须使用具体日期，例如 2026-09-27，不要只写“今天”或“最近”。来源链接要紧跟在相关结论旁，并在来源记录中再次列出。如果来源无法打开，不得把搜索摘要当作已验证证据。

## 交接与确认

报告末尾必须加入用户确认区：

## 待用户确认
- 选择的题材方向：
- 是否调整目标观众或平台：
- 是否进入故事概念开发：是/否
