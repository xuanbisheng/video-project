# 短片故事开发

在题材研究完成后，或用户已经提供短片创意时使用本 Skill。目标是把受众机会转化为原创、可制作的故事方向。本阶段不写完整剧本。遇到“给我几个创意”“脑洞一下”“重新想一版”这类开放请求时，先进入创意发散模式，再等待用户选择方向。

## 输入信息

- 项目简报：时长、平台、观众、语言、类型、基调和内容边界；
- 已确认的题材研究报告或用户提供的故事创意；
- 用户提供的参考作品，只能作为气质或结构参考；
- 制作限制，例如场景数量、演员数量、特效和 AI 生成限制。

如果时长、受众或类型会明显改变故事方案，应先询问用户。

## 工作流程

1. 明确短片要给观众带来的情绪体验和核心承诺。
2. 先写清故事骨架：谁是主角、当前处境、具体目标、为什么现在必须行动、主要阻碍、失败代价、关键选择和结尾情绪。不能只写世界观或一串事件。
3. 从趋势中提炼创作机会，不能复制已有视频的剧情、人物、对白、标题或独特表达。
4. 生成 3 个真正不同的故事方案，除非用户明确指定其他数量。差异应来自核心冲突、主角策略、升级方式和结局，而不是只更换人物姓名。
5. 每个方案必须包含：暂定片名、一句话梗概、类型与基调、主题、主角、目标、动机、时间压力、阻力、失败代价、核心冲突、结局方向、开场钩子、视觉引擎、原创角度、短片适配度和制作风险。
6. 对方案进行排序并解释原因。优先选择有明确视觉引擎、前一分钟有钩子、演员和场景规模可控、结局有力度的方案。

## 故事成立检查

- 一句话必须能说清“谁为了什么，遇到什么阻碍，最后付出什么代价”。“发生了很多事”不等于故事。
- 阻碍必须具体、递进并造成损失；每次尝试都要让局势更难、更危险或更可笑。
- 主角每一段都要主动行动或做判断，不能只是被事件推着走。
- 转折必须改变目标、信息或代价；高潮必须落在主角选择，而不是突然解释真相。
- 结尾要给出可见结果和情绪余味，禁止用“其实是梦”抹掉前面发生的事。

## 创意发散模式

这是面向开放式题材请求的默认输出方式，参考“同一题材、多个风格方向”的创意提案结构。图片或参考材料只提供结构、气质和发散幅度，不自动成为故事正典；其中出现的具体标题、人物、设定、台词和桥段不得照搬。

当用户只给出一个题材或一句创意时：

1. 默认产出 5 个方向；若用户明确要求其他数量，以用户数量为准。5 个方向要有明显风格跨度，至少覆盖：一个硬规则/高概念方向、一个荒诞喜剧方向、一个悬疑或解谜方向、一个治愈或情感方向、一个策略/行动方向。题材不适合某一类时，可以替换，但要说明替换理由。
2. 每个方向使用短而具体的卡片格式：
   - **风格标签与片名**：让用户一眼看出类型差异。
   - **背景**：交代世界状态、触发事件和主角为什么必须行动。
   - **玩法/故事机制**：说明主角反复做什么、遵守什么规则、如何产生画面和笑点；不要只写抽象主题。
   - **核心矛盾与升级**：明确阻力如何逐步变大，以及主角的策略如何变化。
   - **结局方向**：给出可执行的反转或情绪落点，不能停在设定展示。
3. 方向之间必须更换至少两项：冲突来源、主角策略、升级方式、叙事视角、结局关系。只更换片名或场景不算不同方向。
4. 每个方向补一句“为什么成立”：指出背景如何导致玩法，玩法如何必然导向结局。发现因果断裂时，先修正设定，不用“脑洞”掩盖漏洞。
5. 发散阶段可以大胆加入拟人化、超现实规则、末日/科幻设定或反常识道具，但新增设定必须服务冲突或笑点；不为了显得宏大而堆世界观。
6. 先给创意简介，不要未经用户选择就继续写故事成稿或完整剧本。结尾提供“推荐方向 + 选择区”。

## 创意卡片的逻辑检查

生成每个方向后，逐项检查：

- **触发因果**：背景中的事件是否真的会迫使主角采取行动？
- **行为动机**：主角为什么选择这个策略，而不是更简单的做法？
- **规则兑现**：设定中提出的规则是否在冲突和结尾中产生后果？
- **升级路径**：每一次尝试是否比上一次更难、更冒险或更可笑？
- **反转公平**：结尾信息是否能从前文找到线索，而不是临时添加新事实？
- **制作边界**：新增角色、地点、动物、复杂特效或高难度 AI 连续性是否被明确标注？

## 自由发挥模式

当用户说“自由发挥”“脑洞一点”“重新想一版”或给出一个开放式创意时，允许在用户核心设定之上主动发明新的喜剧机制、视觉规则、误导线索、道具用途和反转关系。自由发挥不是换几个名字，而是可以改变主角的行动策略、升级路径和结局视角。

执行自由发挥时必须遵守：

- 保留用户明确指定的核心前提、时长、平台、类型、基调和内容边界；如果要改变其中任何一项，先标注为“开放决策”。
- 至少提供一个超现实或高概念方案，以及一个更生活化、低成本的方案；两者都要能在用户指定时长内闭合。
- 每个新增的关键脑洞都要说明它如何服务笑点、反转或视觉表达，不能只堆叠奇观。
- 新增角色、地点、动物、复杂特效或高难度 AI 连续性时，必须在制作风险中明示，不得默默扩大制作规模。
- 不复制现成视频的标题、台词、人物、标志性桥段或独特呈现；可以借鉴观众需求和冲突模式，但要换成新的因果链。
- 涉及动物时，喜剧冲突不以伤害、窒息、危险食物或惩罚为笑点；优先使用误会、欲望、伪装、道具和人类自作聪明制造反转。

输出时在每个方案中增加“自由发挥点”，并在推荐部分解释最有价值的脑洞与其制作取舍。进入创意发散模式时，优先使用上述“背景—玩法/故事机制—核心矛盾与升级—结局方向”的卡片结构；用户选定方向后，再恢复完整方案字段。

## 输出格式

生成 02_concept_options.md，包含：

- 项目假设和题材来源；
- 所有方案的对比表；
- 每个方案的详细说明；
- 推荐方案和取舍；
- 会改变推荐结果的待确认问题。

不得在本阶段编造市场数据。引用趋势结论时，必须回指题材研究报告。

## 交接规则

结尾必须加入用户选择区。在用户选择方案，或明确要求合并方案前，不得调用 story-drafting。如果用户要求合并，必须明确哪个方案是基础，以及从其他方案借用了哪些元素。
