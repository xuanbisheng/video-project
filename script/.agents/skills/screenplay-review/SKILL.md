# 短片剧本审查

只有在剧本初稿已经存在，并且用户授权审查后，才能使用本 Skill。审查对象包括已确认的 03_story.md、项目简报以及平台和制作限制。本 Skill 只做诊断，不自动改写剧本。

## 审查维度

- 故事前提和开场钩子：开场是否提出明确问题或承诺；
- 故事骨架：能否一句话说清主角、目标、阻碍、代价和选择；
- 主角和对立力量：目标、动机、时间压力、选择和升级是否清晰；
- 结构和节奏：每场戏是否改变局势，短片是否能够抵达有效高潮；
- 人物弧光和主题：人物变化和主题意义是否通过行动获得，而不是直接宣告；
- 对白：声音是否区分、潜台词是否有效、信息是否自然；
- 连续性：时间、空间、物件、伤势、信息状态以及因果关系；
- 视觉叙事：每个关键动作是否承担明确剧情任务，是否有必要的异常、反应和结尾钩子；
- 美学连续性：构图、视点、光源方向、色彩、材质和角色/道具外观是否像同一部片；
- 原创性和参考距离：是否出现对参考作品的无意复制；
- 制作可行性：场景、演员、道具、特效、声音和 AI 生成风险；
- 受众适配：基调、内容边界和平台适配度。

## 问题分级和证据

每个问题必须归类：

- A 级：不修改就会影响故事成立；
- B 级：会明显削弱观感或制作可行性；
- C 级：可选的润色问题。

每个问题都要写明场次或台词位置、实际问题、影响原因和具体修复方向。不要在审查报告中直接重写场景，也不要擅自发明替代结局。

优先指出这些高频失败模式：只有设定没有目标、事件堆砌、阻碍不递进、结尾没有代价、抽象情绪不可拍、台词重复已知信息。

## 输出格式

生成 06_review_report.md，包含：

- 总体结论和置信度；
- 各审查维度评分表；
- 带等级和位置的问题清单；
- 值得保留的优点；
- 能解决主要问题的最小修改路径；
- 仍然存在的不确定性和需要用户回答的问题。

结尾必须询问用户选择“只处理 A 级”“处理 A+B 级”“处理全部问题”或“保持原稿”。只有用户做出选择后，剧本写作 Skill 才能生成 07_final_screenplay.md。
