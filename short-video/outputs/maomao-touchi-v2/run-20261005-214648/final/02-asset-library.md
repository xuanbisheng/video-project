# 资产库

## 使用说明

- 项目：maomao-touchi-v2
- 画幅：视频 9:16；资产参考图按主体职责单独生成
- 优先级：P0 为连续性核心；P1 为动作与空间关系；P2 为背景声音或后期元素
- 角色资产必须引用 CHAR_001、CHAR_002；不制作角色三视图
- 资产状态分为 LOCKED（跨镜头锁定）和 SHOT_VARIABLE（仅本镜头变化）

| ID | 名称 | 优先级 | LOCKED | SHOT_VARIABLE | 参考图职责 |

## 场景资产

### ASSET_101 客厅全屋与矮柜门缝

- 优先级：P0
- 视觉：微缩盒子式高机位俯视构图，前墙压低为白色半墙剖面，后墙与左侧窗墙可见，天花板不入画；后墙偏左浅橡木矮柜、一扇柜门半开成竖直猫门缝，右侧米白布艺沙发配暖橙靠垫、上方原木搁板小画框，左侧白框大窗暖光在木地板拉出长条光斑，前景木地板留空、地面干净无杂物；空场景，不含任何可移动道具
- LOCKED：高机位微缩盒子构图与白色半墙剖面不变；仅含固定家具（矮柜、门缝、沙发、搁板），重拍器、水盆、手机支架等道具不入本图，道具位置由分镜控制并后期合成；储物柜门缝是团团入口，矮柜高度、木纹和门缝宽度不变；窗光从同一侧进入；后墙与左侧窗墙同时可见，地面主导画面
- SHOT_VARIABLE：机位俯角、前景虚化、阳光面积、门缝阴影、灰尘可见度、靠垫颜色
- 参考图职责：锁定全屋空间布局、轴线、矮柜与窗边相对关系；兼作团团门缝钻出与回溯归位的入口锚点，局部机位由本图裁切派生；不承担任何道具的位置锚定

### ASSET_103 窗边阳光区

- 优先级：P1
- 视觉：客厅靠窗地面或低矮软垫，周末下午自然暖光
- LOCKED：温毛巾最终铺在此处
- SHOT_VARIABLE：光斑大小和背景虚化

## 道具资产

### ASSET_001 黑色三秒重拍器

- 优先级：P0
- 视觉：掌心大小黑色设备，四格指示灯和单个按键，边缘有轻微使用磨痕
- 状态序列：第一触发蓝；第二触发蓝；第三触发黄；最后一次红灯锁死并熄灭
- LOCKED：灯色顺序、按钮位置、黑色外壳、与矮柜/地面的相对位置
- SHOT_VARIABLE：灯光亮度、被猫爪触碰角度、手掌握持角度
- 参考图职责：锁定设备外形和灯位，不承担角色身份

### ASSET_002 浅黄色浴巾

- 优先级：P1
- 视觉：柔软浅黄色棉质浴巾，边缘自然卷曲
- LOCKED：小林开场拿入；中段放下并推到画外；结尾松松包住团团
- SHOT_VARIABLE：折叠形态、局部褶皱和包裹松紧

### ASSET_003 温毛巾

- 优先级：P0
- 视觉：干净浅暖白小毛巾，铺在窗边阳光里，后段向团团方向推近
- LOCKED：不浸水；只擦团团背部和爪边
- SHOT_VARIABLE：铺展角度、阳光高光、擦拭次数

### ASSET_004 灰色水盆

- 优先级：P0
- 视觉：低矮灰色塑料盆，内有少量温水
- LOCKED：靠近手机支架和团团活动区；高潮只表现盆沿移动、水平晃动、长滴声；之后移远
- SHOT_VARIABLE：倾斜角、水平波纹、地面反光

### ASSET_005 小鱼干

- 优先级：P0
- 视觉：一根短小棕金色鱼干，碎屑少量散落
- LOCKED：同一根鱼干在每次回溯后回到原位置；结尾小林另放第二根
- SHOT_VARIABLE：猫叼住的角度、碎屑位置，但不能凭空增加数量

### ASSET_006 手机支架与拍摄提示灯

- 优先级：P1
- 视觉：简洁手机支架，提示灯持续亮着，靠近矮柜
- LOCKED：支架稳定不倒；倒计时和字幕后期添加
- SHOT_VARIABLE：画面占比、反光强度

### ASSET_007 扫地机器人

- 优先级：P2
- 视觉：不必出镜，仅作为客厅画外靠近声
- LOCKED：只使用声音，不新增角色或运动主体

## 跨资产关系

- CHAR_001 团团 ↔ ASSET_001：猫爪按键，灯色是回溯次数连续性锚点
- CHAR_001 团团 ↔ ASSET_005：每次重新冲向同一根鱼干；结尾叼走鱼干
- CHAR_002 小林 ↔ ASSET_002/003/004：浴巾、温毛巾和水盆展示照护策略变化
- ASSET_001/004/006/101：重拍器、水盆、支架均为独立道具参考，ASSET_101 出空场景，道具位置由分镜控制并后期合成到场景上
- ASSET_003/103：温毛巾与窗边阳光区共同构成安全清洁终点

## 禁止漂移

- 不增加额外人物、额外猫、额外鱼干或额外重拍器
- 不改变团团左耳深色毛和绿色项圈
- 不将小林服装改为外出服或夸张配饰
- 不生成三视图；不把 H3 参考图写成角色三视图
