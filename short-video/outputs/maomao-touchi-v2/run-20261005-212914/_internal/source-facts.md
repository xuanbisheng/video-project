# Source Facts

## 项目

- 片名：《再来一次，我就洗澡》最终剧本（v2）
- 类型：AI 原生家庭喜剧 / 有限次数时间回溯
- 时长：约 3 分钟；抖音竖屏；中文；9:16
- 制作规模：一只猫、一位主人、一个客厅；回溯用固定构图剪辑

## 已确认角色

### CHAR_001 团团

- 橘白短毛猫；左耳深色毛为长期识别点；绿色项圈锁定
- 开场临时状态：左耳沾灰、嘴边半截小鱼干、爪边鱼干酱
- 记得三秒回溯；会主动按黑色三秒重拍器；最终自主走上温毛巾
- 表演边界：不生成被浸水、窒息、惊吓或强行惩罚画面

### CHAR_002 小林

- 用户确认：大学刚毕业、萌宠博主、温柔、有爱心
- 用户确认造型：浅灰或米白上衣、深色长裤、室内拖鞋
- 用户确认出镜：以手部、腿部、半身和声音为主，允许少部分自然露脸
- 剧本行为：拿浴巾、检查设备、铺温毛巾、坐远等待、移开水盆、推毛巾、擦背和爪边、递鱼干
- 互动边界：不抓、不抱、不强行浸湿团团

## 场景与资产

- SCENE_001：周末下午客厅；矮柜、储物柜门缝、沙发、窗边阳光区、手机支架和团团活动区保持相对位置
- ASSET_001：黑色三秒重拍器，灯色蓝、蓝、黄、红锁死；锁死后不再亮
- ASSET_002：浅黄色浴巾
- ASSET_003：温毛巾
- ASSET_004：灰色水盆和温水
- ASSET_005：同一根小鱼干；结尾另放第二根
- ASSET_006：手机支架与拍摄提示灯；倒计时和字幕后期添加
- ASSET_007：扫地机器人，仅画外声
- ASSET_008：矮柜与储物柜门缝
