# Source Facts

## 来源与项目元数据

- 来源剧本：《再来一次，我就洗澡》最终剧本（v2）
- 类型：AI 原生家庭喜剧 / 有限次数时间回溯
- 时长：约 3 分钟
- 平台：抖音竖屏
- 画幅：9:16
- 语言：中文
- 制作规模：一只猫、一位主人、一个室内场景
- 视觉总原则：回溯通过固定构图和同构剪辑完成，不生成长段倒放

## 角色事实

### CHAR_001 团团

- 角色类型：动物主角，橘白短毛猫
- 剧情功能：主动发现并利用三秒重拍规则，推动喜剧循环，最后从逃避转向自主清洁
- 外观事实：橘白短毛；左耳有深色/灰色识别区域；绿色项圈
- 开场状态：左耳沾灰；嘴边挂半截小鱼干；爪边粘鱼干酱
- 关键能力与知识：记得每次回溯；能判断重拍器状态；主动按下设备
- 关键动作：钻出储物柜、跳上沙发、压低身体、扫尾、冲向同一根鱼干、按重拍器、最后走上温毛巾
- 结尾状态：被毛巾松松包住，叼走鱼干，尾巴尖仍朝向熄灭的重拍器弯着

### CHAR_002 小林

- 角色类型：人类主人
- 剧情功能：提出清洁压力并逐步理解团团的规则，最终以不强迫的方式照顾团团
- 用户指定身份：大学刚毕业；萌宠博主
- 用户指定性格：温柔；有爱心
- 剧本动作事实：拿浅黄色浴巾；检查重拍器；蹲在设备旁；把温毛巾铺到窗边阳光里；坐远并把双手放在膝盖上；移远水盆；推温毛巾；只擦背和爪边；递鱼干
- 表演边界：不抓、不抱、不强行浸湿团团；主要以手部、腿部、半身和声音出现
- 关键台词：“三分钟后开拍。只擦一下，不泡水。”“你在重拍？”“不抓你。擦一下，晒太阳。”

## 场景事实

### SCENE_001 客厅，周末下午

- 固定空间：矮柜、沙发、窗边阳光区、手机支架、灰色水盆、团团活动区
- 空间关系：手机支架靠近矮柜；水盆靠近手机支架和团团活动区；小林脚边交代支架与水盆位置
- 光线：周末下午自然光；窗边有可见阳光；整体为温暖、生活化室内光
- 声音锚点：手机拍摄提示灯环境声、重拍器滴声/长滴声、画外扫地机器人靠近声

## 资产事实

- ASSET_001 黑色三秒重拍器：四格指示灯，状态按蓝、蓝、黄、红锁死推进；锁死后永不再亮
- ASSET_002 浅黄色浴巾：小林拿取、放下、推到画外；结尾用于松松包住团团
- ASSET_003 温毛巾：铺在窗边阳光里，后段推向团团并完成擦拭
- ASSET_004 灰色水盆：温水；高潮拆为盆沿移动、水平晃动、长滴声三段；不可生成完整液体倾倒
- ASSET_005 小鱼干：同一根鱼干被反复重新取回，不得凭空增加；结尾小林另放第二根
- ASSET_006 手机支架与拍摄提示灯：靠近矮柜，提示灯保持亮着；倒计时和字幕后期添加
- ASSET_007 扫地机器人：只作为画外声音，不必露出
- ASSET_008 矮柜与储物柜门缝：团团开场从门缝钻出，构成回溯归位锚点

## 高影响连续性约束

- 竖屏 9:16；客厅中景、矮柜、手机支架和活动区的相对位置保持稳定
- 重拍器灯色严格为蓝、蓝、黄、红锁死；锁死后永不恢复
- 回溯用同构镜头剪辑和物件归位表现；不要求模型生成长段倒放
- 鱼干数量和位置必须有因果；团团每次重新冲向同一根鱼干
- 水盆高潮只做盆沿移动、水平晃动、长滴声三段素材
- 倒计时、循环字幕、结尾字幕全部后期添加
- 不生成猫被浸水、窒息、惊吓或强行惩罚画面
- 正式生成前仍需做团团角色参考测试和水盆倾斜动作测试
