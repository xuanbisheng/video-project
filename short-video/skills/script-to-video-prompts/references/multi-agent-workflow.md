# Multi Agent Workflow

这是一个逻辑分工协议。默认由一个 Agent 在同一会话内自动按阶段执行；只有角色设计需要用户确认，其他阶段不再逐步暂停。

## 阶段顺序

1. `script-parser`：识别人物、地点、时间、动作、情绪、道具、转折和潜在视觉线索；不写最终提示词。
2. `story-checker`：用目标、动机、阻碍、转折、选择、代价、落点检查故事可拍性；问题先列为待确认。
3. `scene-splitter`：拆场景和视频单元；长视频单元不超过 15 秒，写起始状态、结束状态和下一条衔接。
4. `character-designer`：根据剧本解读生成角色设计审核稿，建立 CHAR_* ID，标记锁定项、可变项和推断设定。
5. `character-review-gate`：等待用户明确确认；修改则回到角色设计，未确认不得进入下游。
6. `asset-planner`：仅使用已确认角色设计，决定场景、道具、服装、关键特效、风格资产和参考图职责。
7. `asset-builders`：分别稳定角色、场景、道具和风格规则；固定描述写入资产 ID。
8. `shot-planner`：每个单元设计 2-4 个镜头任务，写景别、机位、运动、构图、光影、声音和剪辑点。
9. `prompt-writer`：按 H3 与 Seedance 输出专用版；不新增剧情或改写已确认角色。
10. `continuity-checker`：检查人物、服装、道具、站位、轴线、光线、声音、时长和前后状态。
11. `exporter`：只汇总六个主交付文件，检查结果留在内部目录。

## 阶段门

- 没有一句话故事或关键动机不清，不进入镜头提示词。
- 没有角色审核通过记录和资产锁定项，不生成需要角色/道具连续性的镜头。
- 没有起始/结束状态，不交付多单元视频提示词。
- 连续性质检存在失败项时，先修正受影响镜头，再导出。

## 最小交付包

最终只导出：角色设计、资产库、Midjourney 资产提示词、剧本分镜、H3 视频提示词、Seedance 视频提示词。连续性质检、待确认问题和原始拆解保存在内部目录，不列入最终交付。
