# Prompt Schema

逐镜头输出使用以下字段。可以用 Markdown 表格呈现，也可以按同一字段导出 JSON/CSV；字段语义不能省略。

## 项目级字段

- `project_title`：项目名。
- `format`：画幅、分辨率、帧率、目标平台。
- `style_bible`：类型、现实/风格化程度、主色、材质和整体摄影气质。
- `continuity_bible`：人物、服装、道具、场景和光线的锁定描述。
- `assumptions`：用户未提供但被采用的默认设定。

## 镜头级字段

```text
镜头编号：S01_SH03
场次：地点 / 时间
叙事目的：该镜头必须让观众看到或感受到什么
时长：X 秒
景别：远景 / 全景 / 中景 / 中近景 / 近景 / 特写
机位与焦段：高度、角度、焦段或等效视角
构图：主体位置、前中后景、视线方向、画面留白
主体与动作：动作起点、过程、终点；只写可见行为
环境与美术：空间、材质、道具、天气、背景活动
摄影机运动：固定、推、拉、摇、移、跟拍、手持等；写明速度
灯光：主光方向、色温关系、反差、轮廓/反光来源
色彩与质感：主色、辅助色、颗粒、镜面/湿润/雾气等材质
情绪：观众此刻应感受到的情绪
对白/音效：只保留与画面同步且可执行的内容
正向提示词：英文，一段可直接复制的模型提示词
负面提示词：英文，针对本镜头的失控风险
参数建议：时长、比例、参考图/首帧、运动强度等
连续性与衔接：与前后镜头的动作、视线、光线和道具关系
风险标记：低 / 中 / 高，并说明原因
```

## 正向提示词顺序

按“主体与动作、环境、美术细节、摄影机与镜头、灯光、色彩与材质、情绪、连续性约束”组织。使用具体可视化名词和动词；不要只写 `beautiful`、`epic`、`cinematic` 等无上下文形容词。

## 负面提示词原则

只写会影响该镜头的风险，例如人物身份漂移、额外人物、肢体变形、错误道具、文字水印、镜头穿模、突然变焦、光线方向反转或不应发生的表情变化。
