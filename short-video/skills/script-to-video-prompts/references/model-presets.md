# Model Presets

V1 采用通用提示词为主、模型适配为辅。不同模型的界面和参数可能变化，不能假设某个平台一定支持某个字段。

## 通用基线

输出主体、动作、环境、摄影、灯光、风格、时长和负面约束；把平台特有参数单独列在“参数建议”，并标记为“需在当前版本界面确认”。

## 适配原则

- **Sora / Veo**：保留自然语言的完整动作和镜头因果，减少关键词堆叠。
- **Runway / Kling / Hailuo**：动作、镜头运动和时长写得更短更明确，降低同句多动作。
- **Seedance 或其他模型**：先使用通用英文提示词；只有用户指定版本或提供官方参数时才增加版本字段。
- **MiniMax H3**：使用官方多模态描述结构。文本生视频优先写 `integrated_multimodal_description`，需要声音时增加 `overall_soundscape` 与 `non_diegetic_music`；图生视频、首尾帧和全参考任务改用对应的参考字段。

## 输出约束

若用户未指定模型，不把提示词写成某个平台的专用语法。若用户指定模型但缺少版本，说明采用的通用假设，并保留一份模型无关版本。
