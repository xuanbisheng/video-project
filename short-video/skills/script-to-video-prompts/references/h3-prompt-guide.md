# MiniMax H3 Prompt Guide

本参考按 2026 年 9 月 27 日可查到的 MiniMax H3 官方 Prompt Guide 整理。H3 支持文本生视频（T2VA）、图生视频（I2VA）、首尾帧生视频（FL2VA）、单图加主体/场景参考（L2VA）以及带多主体和场景参考的全参考模式。

## H3 的核心写法

H3 不是单纯关键词堆叠。优先使用自然语言和结构化多模态描述，把“谁/什么 + 做什么 + 在哪里 + 如何拍 + 听到什么”写成可执行的时间线。

通用视频段落顺序：

1. 主体与身份：人物、物体、服装、颜色、材质和固定特征。
2. 动作与时间：动作起点、动作过程、动作终点，以及时间点或时间区间。
3. 场景与光线：地点、空间关系、天气、时间、光源、色彩和材质。
4. 摄影机：景别、视角、焦段感、推拉摇移、跟拍、手持或固定。
5. 声音：环境声、动作声、对白、音乐和声画关系。

## T2VA / I2VA 基础结构

文本生视频和单图生视频可采用以下字段：

```text
integrated_multimodal_description:
[Shot 1] ...
[Shot 2] ...
overall_soundscape: ...
non_diegetic_music: ...
```

`[Shot N]` 用于有序描述镜头或时间段；镜头内要写清主体、动作、场景、摄影和光线。没有音乐时明确写 `None` 或“无非叙事音乐”，不要让模型自行添加音乐。

## FL2VA 首尾帧

首尾帧任务要描述从起始图像到结束图像之间的变化：

```text
keyframe_description:
At 0.00 seconds, ...
At 5.00 seconds, ...
transition_description:
...
overall_soundscape: ...
non_diegetic_music: ...
```

重点写动作和镜头如何从起点过渡到终点，不要重复静态图像里已经清晰可见但不会变化的细节。

## L2VA / 全参考模式

当任务包含主体参考、场景参考或多个角色时，先建立稳定的引用定义，再写镜头：

```text
subject_definitions:
<Subject 1> ...
<Subject 2> ...
scene_definition:
...
summary:
...
retention_analysis:
...
detailed_description:
[Shot 1] ...
overall_soundscape: ...
non_diegetic_music: ...
```

每个主体定义只描述其身份、外观、服装、状态和与其他主体的关系；镜头段落通过 `<Subject 1>` 等引用保持一致。`retention_analysis` 说明哪些主体、场景、道具必须在视频中保留。

## H3 镜头设计规则

- 一个 Shot 只承担一个主要动作或一个清晰的情绪转折。
- 用时间顺序写动作，不要把多个同时发生的动作压成含糊的长句。
- 把“紧张、孤独、温暖”等抽象词转译成表情、姿态、速度、光线、环境声和镜头距离。
- 需要连续性时重复关键锁定特征，但不要每个 Shot 复制整段角色百科。
- 结尾写清停留姿态、视线方向、镜头运动状态或声音尾巴，便于剪辑和下一镜头衔接。

## H3 声音规则

- `overall_soundscape` 写环境声、动作声、对白口吻和声源位置。
- `non_diegetic_music` 只写画外音乐；若不需要音乐，明确写无。
- 声音描述应服务于画面，不要用一长串歌曲名、艺术家名或无法验证的风格标签代替声音设计。

## 与通用版的边界

通用版保留导演、摄影、灯光和剪辑信息，但不强制使用 H3 字段名。H3 版必须保留官方字段结构，方便直接复制到 H3 工作流；两份文件的镜头编号和剧情动作必须完全对应。
