# Midjourney V8.2 Guide

本参考按 2026 年 9 月 27 日可查到的 Midjourney 官方文档整理。当前默认版本为 V8.2，V8.2 于 2026 年 7 月 24 日作为默认版本发布。

## Prompt 结构

使用短而具体的自然语言，通常按以下顺序：

```text
主体 / 资产 + 媒介或展示方式 + 环境 / 背景 + 光线 + 颜色与材质 + 情绪或气质 + 构图 / 视角 + 参数
```

官方提示建议强调主体、媒介、环境、灯光、颜色、情绪和构图；长串指令、堆叠形容词和互相冲突的要求会降低可控性。

## V8.2 资产一致性

- V8.2 的 Edit Model 可用文字指令编辑图片，并支持最多四张参考图。
- V8.x 用 Edit Model 替代 Omni Reference、Character Reference 和 Retexture。
- 因此，角色/道具/场景资产输出中要单独列 `reference_images` 和 `edit_instruction`，但不要默认生成 V7 的 `--oref`。
- Image Prompt 是启发式参考，不等同于精确复制；需要精确修改时提示用户使用 Editor/Edit Model。

## 参数位置与写法

- 所有参数放在提示词末尾。
- 正文与参数之间留一个空格。
- 参数内部使用空格，不写逗号、句号等标点。
- 参数之后不要再写正文。
- 没有必要时不显式写 `--v 8.2`；需要锁定版本或交付可复现 Prompt 时再写。

## V8.2 常用参数

- `--ar`：画幅比例。角色通常使用 `2:3` 或用户指定比例；道具常用 `1:1`；场景常用 `16:9`。
- `--raw`：需要更少默认风格、更直接遵循文字时使用。
- `--s`：控制风格化程度；默认只在需要风格对比时显式设置。
- `--c`：控制结果变化幅度；资产连续性任务通常保持较低值。
- `--no`：排除明确不需要的元素，放在末尾。
- `--seed`：用于测试和复现，不等于跨资产锁定身份。
- `--sref` / `--sw`：使用风格参考时单独列出；不要把风格参考当作角色身份参考。
- `--p`：只有用户已有 Personalization profile 时才加入。

## 参考图规则

参考图 URL 或图片引用放在文字提示之前，文字提示仍需完整写出最终希望看到的内容。不同版本的 `--iw` 支持范围可能不同；未确认版本兼容性时不硬编码数值。

## 负面约束

优先写正向描述；必须排除时使用 `--no`。`--no modern clothing` 这类短语可能被逐词读取为“no modern”和“no clothing”，因此应改为正向指定服装，或使用更明确、可分词理解的排除项。

## 版本兼容

若用户明确要求 V7，才使用 V7 专属的 Omni Reference 写法并在文件头标注 `Legacy V7`。若用户未指定版本，所有提示词均按 V8.2 规则生成。
