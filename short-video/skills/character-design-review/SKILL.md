# Character Design Gate

这是 video-prompt-director 调用的内部角色设计 Skill，不是独立的最终交付 Agent。目标不是写百科式人物小传，而是建立一张能被资产库、分镜和 H3/Seedance 持续复用的短视频角色卡。

## 唯一人工闸门

1. 从剧本和用户资料提取角色，建立稳定 CHAR_* ID。
2. 每次执行都在新的 outputs/<project-slug>/run-<timestamp>/ 目录生成角色设计审核稿，状态设为“待角色审核”；不得写入历史运行目录。
3. 用户可以确认或提出修改；修改只回到角色设计，不进入下游。
4. 用户明确确认后，将批准版整理为 final/01-character-design.md，冻结锁定项，并自动继续资产库、分镜、H3 和 Seedance。

角色设计 Skill 或 Agent 更新不会回写历史审核稿；任何修改、重跑或模型切换都创建新的运行目录。

## 角色卡的必需层级

每个角色必须包含以下四层；没有对白的角色也必须有动作或声音锚点：

### A. 短视频识别层

- 姓名 / 代号、CHAR_* ID、角色类型。
- 年龄或年龄感；动物、怪物或非人角色优先写年龄感，不强制数字年龄。
- 外观只保留 1—2 个高记忆点，不堆百科式细节。
- 身份、职业、社会地位、叙事功能。
- 外在人设：角色希望别人看到的形象。
- 性格标签：1 个主标签 + 1 个副标签，必须能转译为动作、表情或语言。
- 口头禅、固定语气、标志性小动作或标志性声音。

### B. 角色内核层

- 目标、欲望、需要、恐惧、缺点、能力和核心矛盾。
- 人物关系、知识状态、边界和人物变化。
- 只记录会影响剧情、决策或表演的心理信息。

### C. 视觉造型层

- 脸部/眼睛/发型或毛发、肤色/毛色、体型、轮廓、姿态和独特标记。
- 服装单独记录：上装、下装、鞋、外套层次、颜色、材质、使用状态和变化条件。
- 首饰与配饰单独记录：身份配饰、动作配饰、是否长期锁定、是否参与动作。
- 关键道具单独记录，不把手持道具误写成服装或首饰。
- 主色、辅助色、材质、时代/地域线索和尺度关系。

### D. 表演连续性层

- 常态表情、压力反应、情绪状态和 1—2 个可见微表情。
- 动作习惯、移动节奏、身体重心、视线习惯和与道具的互动。
- 声音、语速、停顿、呼吸、重音、尾音；无对白角色写非语言声音。
- 跨镜头锁定项、可变项、状态变体和前后镜头承接规则。

## 信息标注规则

每个重要字段标注为：

- 剧本事实：剧本明确写出。
- 用户指定：用户明确提供或确认。
- 推断设定：为生成而补充的保守设定。
- 待确认：会影响角色识别、剧情理解或连续性的未决内容。

不得把推断设定写成剧本事实。高影响待确认项最多列 3—5 个，优先询问真正会影响后续生成的选择。

## 设计决策规则

- 性格标签最多两个；标签必须有对应的可见证据。
- 外观记忆点最多两个；其余外观细节只有在镜头或资产连续性需要时才加入。
- 服装、首饰/配饰、关键道具必须分栏；身份配饰和动作配饰必须分开。
- 角色设计不新增人物、关系、剧情或结局。
- 不默认制作角色三视图；只有用户明确要求或确有外观审阅需要时才制作。
- H3 不要求角色三视图或默认身份参考图；确需身份参考时使用单主体、单视角图片。

## 下游契约

资产库引用已确认的 CHAR_*、服装、配饰和关键道具锁定项；分镜只引用批准版角色卡，不重新发明角色外观；H3/Seedance 只改变模型表达，不改变角色事实。

详细字段顺序、角色类型差异和审核格式见 references/character-design-schema.md。
