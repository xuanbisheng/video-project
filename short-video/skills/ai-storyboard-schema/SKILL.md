# AI Storyboard Schema

项目级字段：project_title、source_scope、story_format、aspect_ratio、frame_rate、total_duration、visual_style_constraints、generation_constraints、assumptions。

场景级字段：scene_id、scene_heading、location、time、dramatic_objective、characters、props、spatial_layout、story_beats、continuity_anchors。每个 `story_beats` 项包含 beat_id、dramatic_purpose、audience_should_see、audience_should_understand、audience_should_feel、visible_change、emotional_change、required_coverage、entry_state 和 exit_state。

镜头级字段：shot_id、sequence_order、continuity_block_id、beat_id、shot_type、narrative_purpose、generation_purpose、duration、prompt_duration_limit、duration_budget、start_state、motion_timeline、end_state、shot_size、camera_height、camera_angle、lens_or_field_of_view、composition、subject_blocking、scene_lock、subject_lock、spatial_anchor、primary_action、secondary_motion、camera_motion、environment_motion、screen_direction、eyeline、axis_status、dialogue、sound、transition_in、transition_out、edit_transition、reference_requirements、keyframe_requirements、generation_mode、prompt_format、generic_prompt、h3_shot_description、continuity_constraints、risk_level、fallback_strategy。

生成计划字段：input_image_required、start_frame_required、end_frame_required、reference_images_required、motion_priority、camera_priority、identity_priority、background_priority、iteration_order。

约束：scene_id、continuity_block_id、beat_id、shot_id 是两份文件的稳定主键；每个镜头必须关联一个 scene_id 和 beat_id；Markdown、JSON、CSV 只改变呈现格式；start_state、motion_timeline、end_state 必须成组出现；narrative_purpose 与 generation_purpose 不得合并；同一 continuity_block_id 下的镜头必须相邻或明确标记跨镜头原因；任何拆镜都要同步更新 sequence_order、duration、起止状态和两种提示描述。
