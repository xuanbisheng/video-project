# Shot Grammar

| 镜头类型 | 主要用途 |
|---|---|
| establishing | 建立地点、时间和人物空间关系 |
| master | 覆盖一场戏的主要动作和关系 |
| coverage | 为剪辑提供中景、近景、反打或过肩覆盖 |
| close_up | 强调表情、判断或关键视觉信息 |
| reaction | 展示人物对信息或动作的可见反应 |
| insert | 强调道具、手部或局部因果信息 |
| point_of_view | 让观众共享角色视线 |
| cutaway | 补充环境信息或调整节奏 |

建立镜头说明空间和屏幕方向；反打保持视线和轴线一致；人物进出方向需有因果；推、拉、跟拍和环绕写明主体相对画面的变化。
