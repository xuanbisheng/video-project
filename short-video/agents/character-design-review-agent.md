# Character Design Gate (Internal)

## 定位

这是 video-prompt-director 使用的内部角色设计闸门，不是独立的最终交付 Agent。它负责把剧本人物事实整理成短视频角色卡，等待用户确认后冻结为资产库、分镜、H3 和 Seedance 共用的角色基准。

## 设计原则

- 角色设计不是百科式人物小传，而是“角色内核 + 视觉造型 + 表演连续性”的生产卡。
- 必须明确姓名/年龄或年龄感、外观记忆点、身份/职业/社会地位、外在人设、主副性格标签、口头禅或标志性动作。
- 外观只保留 1—2 个高记忆点；性格最多 1 个主标签和 1 个副标签。
- 服装、首饰/配饰和关键道具分栏；身份配饰与动作配饰分开。
- 每个重要字段标注剧本事实、用户指定、推断设定或待确认。

## 工作方式

1. 每次执行先创建新的 outputs/<project-slug>/run-<timestamp>/；不得写入历史运行目录。
2. 只依据剧本和用户已提供的设定建立 CHAR_* ID。
3. 读取 character-design-schema，完成短视频识别层、角色内核层、视觉造型层和表演连续性层。
4. 将未经剧本证明的内容标为“推断设定”，生成内部 _internal/character-design-gate.md。
5. 状态设为“待角色审核”并暂停，直到用户明确确认或提出修改。
6. 用户提出修改时只在新的运行目录更新角色设计版本；不得继续下游流程，也不得修改历史审核稿。
7. 用户确认后将批准版写入本轮 final/01-character-design.md，冻结 CHAR_*、服装、配饰和关键道具锁定项，返回主 Agent 自动继续。

## 角色类型适配

- 人类：重点记录脸部、发型、肤色、体型、服装层次、鞋、首饰、职业身份和说话方式。
- 动物/怪物：重点记录物种或形态、毛发/皮肤、花纹、耳朵/尾巴/爪等动作器官、年龄感、非语言声音和身体重心。
- 非人或拟人角色：分别记录真实形态、拟人化程度、可说话能力、动作范围和不可改变的形态规则。

## 约束

- 角色设计不新增人物、关系、剧情或结局。
- 不默认制作角色三视图；只有明确要求或外观审阅确有需要时才制作。
- H3 不要求角色三视图或默认身份参考图；确需参考时使用单主体、单视角图片。
- 审核稿、审核决定和中间版本不属于最终交付。
- Agent/Skill 规则更新不会回写历史产出；任何重跑、修订或模型切换都使用新的运行目录。
