## 1. 剧本事实

### 1.1 项目与画面约束 [剧本事实]

- 类型：AI 原生家庭喜剧／有限次数时间回溯；时长约 3 分钟；抖音竖屏 9:16。
- 场景：周末下午的普通客厅，单场景。
- 角色只有两个：橘白猫团团、主人小林。
- 回溯以固定构图剪辑与物件归位表现，不生成连续倒放。
- 小林主要以手部、腿部、半身和声音参与镜头，但完整人物基准必须先定义。
- 安全限制：不生成猫被浸水、窒息、惊吓或强行惩罚的画面；清洁只表现温毛巾擦拭。
- 屏幕倒计时、循环字幕与结尾字幕全部后期添加。

### 1.2 团团 [剧本事实]

- 物种与外观：橘白短毛猫；左耳有深色毛；佩戴绿色项圈。
- 开场状态：左耳沾灰，嘴边挂着半截小鱼干，爪边粘有鱼干酱；从储物柜门缝钻出。
- 行为：跳上沙发蜷卧、装作晒太阳；看到浴巾后耳朵压平、身体后移；抬爪主动按下重拍器；反复冲向同一根鱼干；最后一次回溯把水盆恢复安全位置；不被强迫地走上温毛巾。
- 情绪弧线：防备洗澡 → 发现并利用回溯规则 → 与小林形成记忆博弈 → 危险出现时选择救场 → 接受有限度照料。
- 结尾动作：被毛巾松松包住，叼走小鱼干；回头触碰已熄灭的重拍器无反应，随后选择第二根鱼干离场。
- 关键视觉关系：绿色项圈、黑色重拍器、小鱼干是识别其行为的三件锚点道具。

### 1.3 小林 [剧本事实]

- 身份：团团的主人。
- 台词三句：准备开拍的安排；「你在重拍？」；「不抓你。擦一下，晒太阳。」
- 行为：拿浅黄色浴巾准备清洁；蹲下检查重拍器；察觉团团记得回溯后收手；把浴巾移开并后退；把温毛巾铺到窗边阳光处；坐远并把温毛巾推向团团；只擦背和爪边，不碰头、不抱起；最后递出小鱼干。
- 关系弧线：从执行清洁计划，转为尊重团团的选择并主动降低压迫感。
- 镜头约束：剧本不要求小林始终露脸；但完整人物基准必须先定义，后续半身、手部、腿部镜头从该基准派生。
- 未指定信息：剧本未给出年龄、性别、是否露脸、服装配色与鞋袜；以上均已由用户于 2026-10-06 拍板（结论见第 7 节），其中**小林为女性**。

## 2. 推荐角色概念

### 2.1 团团：会利用规则的三维动画橘白猫

#### 视觉定位 [推断设定]

前置约束：阶段 0 已锁定 Pixar 三维动画方向，因此**「写实家猫」不再是目标**；本稿按动画化造型给方向，但保留可信猫科结构与四足着地。

- 造型方向：皮克斯式的圆润讨喜——圆脸、短鼻、眼睛偏大且富有表情，短而有力的四肢，躯干略圆润但不肥胖。
- 结构底线：**四足着地，不立行，不使用人类手掌**。按按钮只用前爪。
- 脸部：动画化的表演重心在眼睛；眉骨与耳根需留足可动范围，用于「警惕→得意→犹豫→放松」的切换。
- 毛发：橘色与奶油白分区清晰，短毛带柔软体积感与次表面散射；允许轻微凌乱感（开场脏污状态需要它）。
- 左耳：深橘或棕橘色毛斑，每张资产必须保留的强识别点。
- 项圈：低饱和绿色窄项圈，配小型金属牌。**不加夸张铃铛**——动画化会放大摆动幅度，既破坏连续性也干扰克制的表演。
- 体型：略圆润但敏捷，确保能完成扑鱼干、抬爪按键、走上毛巾三类动作。
- 眼睛颜色：**金黄色**（用户 2026-10-06 确认）。与橘白毛色同色系，与低饱和绿项圈形成冷暖对比；Pixar 方向放大了眼睛的戏份，此项已锁定，所有资产不得漂移。
- 体型倾向：**略圆润**（用户 2026-10-06 确认），同时保持敏捷，确保能完成扑鱼干、抬爪按键、走上毛巾三类动作。

#### 表演方向 [推断设定]

- 防备：耳朵压平，身体后缩，前爪收紧，尾巴低位轻扫。
- 记住规则：低头看重拍器，再看小林；靠**视线切换**而非表情变形交代心理。
- 得意：回头看小林，重心前倾，尾巴尖微抬或弯向设备。
- 犹豫：在温毛巾、重拍器与水盆之间来回看，前爪停在半空。
- 放松：闭眼接受背部和爪边擦拭，尾巴尖仍朝向设备，保留戒心。
- 喜剧底线：笑点来自**行为与视线的反差**，不来自夸张变形表情。

### 2.2 小林：克制、温和的居家主人

#### 视觉定位 [推断设定，已确认]

- 性别：**女性**（用户 2026-10-06 更正）。造型按年轻女性处理；此前按男性拟定的措辞已全部改写。
- 动画语言：与团团同一套三维动画语言；适度夸张但可信的**年轻女性**比例，圆润友善的面相，不做偶像化。
- 身形：年轻女性体型，清瘦自然，便于完成蹲下、后退、坐地动作。
- 发型与面部：**深色低马尾**（用户 2026-10-06 确认），束于颈后低位、居家随意；表情克制，主要通过姿态与手势表达让步。
- 上装：浅灰棉质居家短袖（按本稿建议采纳，作为主色全片固定），无品牌、无复杂图案。
- 下装：深灰直筒家居长裤，裤脚不过度堆叠，确保全身图能看清腿部姿态。
- 鞋袜：**浅色室内拖鞋**（用户 2026-10-06 确认），全片固定，不得在镜头间变化。
- 配色：灰、米白、浅黄与团团的橘白形成区分；避免大面积纯黑。
- 道具状态：浴巾与温毛巾是剧情道具，不作为固定服装；中性基准不拿道具。
- 年龄感：**约 20 岁、大学刚毕业**（用户 2026-10-06 确认），属视觉设定而非剧本事实。
- 造型影响：20 岁要求整体年轻化——身形偏清瘦、气质接近刚独立生活的年轻人，**避免生成成中年形象或男性化特征**。这是本稿相对通用方案的关键约束。
- 年龄备注：20 岁对应「刚毕业」偏年轻（常见毕业年龄为 22 岁前后）。本稿按用户设定执行；若后续系列内容需要交代学制或职业，再补充即可。
- 露脸程度：**角色基准露脸**（用户 2026-10-06 确认）；正式镜头仍可按剧本只用手部、腿部与半身。

#### 身体语言 [推断设定]

- 前期：拿浴巾靠近，身体略向前，动作谨慎但仍有执行感。
- 察觉异常：提前收手，肩膀放松，掌心可见，减少压迫感。
- 后退阶段：坐远、双手放在膝盖上，身体轴线避开团团，表示不抓、不追。
- 结尾：只推动温毛巾或递出鱼干，不突然伸手抱猫；动作慢而可预测。

### 道具与比例锚点 [剧本事实＋推断设定]

- 黑色三秒重拍器：固定放在矮柜附近；四格灯按蓝、蓝、黄、红锁死变化，锁死后永不再亮。
- 浅黄色浴巾与温毛巾：颜色与用途不得互换；清洁只表现擦拭。
- 灰色水盆：能与小林脚部、手机支架、团团形成可信尺度关系。
- 小鱼干：团团每次重新冲向同一根，不凭空增加；结尾第二根属剧情新增，不是回溯复制。
- 手机支架：作为客厅构图锚点，位置保持稳定；屏幕文字后期添加。
- 尺度要求：团团体型需与沙发、矮柜、水盆、手机支架保持可信比例；重拍器为掌大小，不得生成成大型设备。
