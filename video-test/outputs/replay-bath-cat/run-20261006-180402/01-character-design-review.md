# 《再来一次，我就洗澡》角色设计审核稿

## 审核状态

- 状态：待角色审核
- 来源：07_final_screenplay.md（最终剧本 v2）
- 项目类型：AI 原生家庭喜剧／有限次数时间回溯
- 目标画幅：9:16
- 本稿用途：冻结角色连续性前的人工审核，不生成图片，不进入正式资产提示词生产

## 1. 项目级视觉边界

### 剧本事实

- 时长约 3 分钟，平台为抖音竖屏。
- 主要空间是周末下午的普通客厅。
- 角色只有橘白猫团团和主人小林。
- 回溯通过固定构图剪辑与物件归位表现，不要求生成连续倒放。
- 小林主要以手部、腿部、半身和声音参与镜头，但后续角色连续性仍需有完整人物基准。

### 推荐但待确认的视觉方向

- 生活化写实家庭喜剧；猫保持真实猫科身体，不生成完整人形猫。
- 光线以周末下午的柔和窗边暖光为主。
- 笑点来自团团的动作、停顿和规则利用，不依赖夸张变形表情。

## 2. 角色卡：团团

### A. 短视频识别层

- character_id：CHAR_TUANTUAN
- name_or_code：团团
- character_type：动物角色／橘白短毛家猫
- age_or_age_feel：[待确认] 成年感或年轻成猫感；剧本未明确数字年龄
- visual_memory_points：
  1. 橘白短毛分区
  2. 左耳明显深色毛斑
- identity_profession_social_status：家养猫，生活空间中的被照料者
- narrative_function：喜剧主角；通过重拍器学习并利用规则，最后主动选择安全清洁
- external_persona：表面抗拒、装作若无其事的家猫
- personality_primary：机警
- personality_secondary：嘴硬而贪吃
- signature_line_or_action：低头看重拍器，再看小林；尾巴尖在放松时仍朝向重拍器
- signature_sound：猫爪触碰设备的轻响与短暂停顿；猫叫声未在剧本中指定

### B. 角色内核层

- goal_desire_need：
  - 眼前目标：避免被强行清洁，保留行动选择权。
  - 深层需要：确认小林会尊重它的边界，并在安全时接受有限度照料。
- fear_flaw_capability：
  - 恐惧／抗拒：浴巾与被追赶带来的清洁压力；具体怕水程度未设定。
  - 缺点：为了逃避清洁反复利用重拍规则，容易把机会当成无限资源。
  - 能力：记得回溯、观察规则、利用唯一鱼干，并在危险出现时改变策略。
- core_contradiction：想逃开清洁，却在水盆可能伤及小林和手机支架时主动回溯救场；想保持高冷，行动又被鱼干牵引。
- relationship_map：与小林是照料者和被照料者；关系从追逐与防备转为保留距离的信任。
- knowledge_state：
  - 第一次回溯后：团团记得，小林不记得。
  - 连续利用规则后：团团知道次数和物件归位规则，小林逐渐观察到异常。
  - 第三次回溯后：小林确认团团在重拍，并开始主动降低压迫感。
  - 最后一格后：团团确认设备锁死，选择用行为而非设备解决问题。

### C. 视觉造型层

- face_or_head：猫科头部比例；脸型、眼睛颜色和鼻口细节未指定，需审核后锁定
- hair_or_fur：橘白短毛；左耳保留深色毛斑；开场可有局部灰尘和鱼干酱
- skin_or_coloration：橘色与白色为固定底色；脏污不能扩散成换毛色
- body_silhouette：保持真实猫科比例；体型、年龄感和尾巴长度待确认
- posture_and_center_of_gravity：耳朵压平时身体后缩；扑鱼干时重心前倾；犹豫时前爪停在半空；走上毛巾时逐步压低身体
- distinctive_marks：左耳深色毛斑；绿色项圈
- costume：无服装
- jewelry_and_accessories：绿色项圈为身份配饰；颜色需固定，是否有额外挂件未设定，不主动新增
- key_props：黑色三秒重拍器、唯一小鱼干、浅黄色浴巾、温毛巾、灰色水盆
- palette_material_period：橘白毛色、低饱和绿色项圈、暖色室内光；现代普通家庭环境

### D. 表演连续性层

- expression_range：装睡／警惕／得意／犹豫／停住观察／闭眼放松
- micro_performance：
  - 看到浴巾：单眼睁开、耳朵压平、身体后移。
  - 理解规则：重拍器与小林之间快速换视线。
  - 掌握机会：冲向鱼干前回头确认小林。
  - 面对水盆：在水盆、重拍器和小林之间来回看。
  - 接受擦拭：闭眼，但尾巴尖仍指向熄灭的设备。
- movement_rhythm：快速冲刺→突然刹住→短暂停顿→小幅试探→自主慢走
- voice_and_speech：无对白；不为团团新增人类台词
- nonverbal_sounds：爪子触碰按钮、跳上沙发、鱼干叼取等动作声；设备提示音属于道具声音
- locked_features：橘白短毛、左耳深色毛斑、绿色项圈、真实猫科身体、尾巴比例、无完整人形身体
- variable_features：耳朵角度、尾巴姿态、灰尘和鱼干酱范围、表情、姿势、与道具的距离
- state_variants：
  - TUANTUAN_S0：开场局部脏污、嘴边半截鱼干、爪边鱼干酱
  - TUANTUAN_S1：第一次回溯后，警惕观察重拍器
  - TUANTUAN_S2：主动冲向鱼干并反复按键
  - TUANTUAN_S3：水盆危机前停住并决定救场
  - TUANTUAN_S4：自主走上温毛巾，接受背部和爪边擦拭
  - TUANTUAN_S5：清洁后被毛巾松松包住，叼鱼干离场
- reference_responsibility：角色审核通过后，使用单主体、单视角的完整全身主参考；动作资产从锁定身份派生，不默认制作多视图拼图

## 3. 角色卡：小林

### A. 短视频识别层

- character_id：CHAR_XIAOLIN
- name_or_code：小林
- character_type：人类角色／团团的主人
- age_or_age_feel：[待确认] 普通成年居家主人；剧本未指定年龄
- visual_memory_points：[待确认] 需要从发型、服装或姿态中选择 1—2 个稳定记忆点
- identity_profession_social_status：普通家庭中的宠物主人
- narrative_function：制造最初清洁压力，并通过退让和等待完成关系修复
- external_persona：做事有计划但最终愿意尊重猫的边界
- personality_primary：克制
- personality_secondary：耐心
- signature_line_or_action：把浴巾移开、坐远、双手放在膝盖上；用“你在重拍？”确认规则
- signature_sound：平静、短句式说话；语气从执行安排转为安抚，具体音色待确认

### B. 角色内核层

- goal_desire_need：
  - 眼前目标：在开拍前清洁团团，避免把猫浸水。
  - 深层需要：从“完成清洁”转向让团团在安全和可选择的条件下接受照料。
- fear_flaw_capability：
  - 剧本未指定明确恐惧，不新增心理创伤设定。
  - 初始缺点：一开始仍以自己的时间表靠近团团。
  - 能力：观察、收手、后退、铺温毛巾并用可预测动作降低压力。
- core_contradiction：想按计划开拍和清洁，却最终接受团团自主决定靠近毛巾。
- relationship_map：与团团是主人和宠物；冲突不升级为惩罚，关系通过空间距离和动作让步修复。
- knowledge_state：最初不知道团团记得回溯；第三次回溯后确认异常；之后主动配合团团而非追赶。

### C. 视觉造型层

- face_or_head：[待确认] 剧本不要求始终露脸；完整基准仍需定义
- hair_or_fur：[待确认] 发型未指定
- skin_or_coloration：[待确认] 肤色未指定
- body_silhouette：[推断设定] 普通成年人体型，需便于蹲下、后退和坐远；不使用夸张或偶像化体型
- posture_and_center_of_gravity：靠近时略向前；发现团团记得后提前收手；后退后坐远，双手放膝；擦拭时保持慢而可预测
- distinctive_marks：[待确认] 不主动新增明显纹身、品牌或复杂发型
- costume：[待确认] 普通居家上装、家居长裤和室内鞋袜；颜色与材质需统一
- jewelry_and_accessories：剧本未指定，不主动新增
- key_props：浅黄色浴巾、温毛巾、小鱼干、手机支架旁的水盆和重拍器周边空间
- palette_material_period：[推断设定] 低饱和居家色，避免大面积纯黑或高辨识品牌；现代普通家庭

### D. 表演连续性层

- expression_range：准备执行／察觉异常／克制停顿／安抚／等待／轻松收尾
- micro_performance：
  - 浴巾入画：动作有执行感但不追赶。
  - 发现团团记得：掌心可见，肩膀放松，提前收手。
  - 等待阶段：身体轴线避开团团，双手放膝。
  - 结尾：只递鱼干或推动毛巾，不突然抱起或抓取。
- movement_rhythm：接近→停住→后退→坐远→慢速推毛巾／递鱼干
- voice_and_speech：剧本明确的三句短台词：准备开拍、确认“你在重拍”、承诺“不抓你”；语速平稳，避免解释规则
- nonverbal_sounds：脚步、坐下、毛巾移动和水盆移动的动作声；不新增夸张叫喊
- locked_features：行为必须保持低压、可预测；不抓猫、不抱起、不把清洁表现为浸水
- variable_features：露脸程度、表情幅度、站蹲坐姿、与团团的距离、浴巾和温毛巾持有状态
- state_variants：
  - XIAOLIN_S0：持浅黄色浴巾靠近
  - XIAOLIN_S1：蹲下检查重拍器
  - XIAOLIN_S2：发现异常后提前收手
  - XIAOLIN_S3：坐远等待并把温毛巾推向团团
  - XIAOLIN_S4：只擦背和爪边，最后递小鱼干
- reference_responsibility：先建立完整全身单视角基准；正式镜头可按剧本裁成手部、腿部、半身或声音主导画面

## 4. 跨角色与道具连续性

- 重拍器是因果道具，不属于任何角色的服装或配饰。
- 绿色项圈是团团身份锚点，不能在回溯或清洁后变色、消失或增加挂件。
- 浅黄色浴巾与暖象牙色温毛巾必须明显区分；清洁只表现擦拭。
- 鱼干数量按剧本管理：团团反复冲向同一根鱼干，结尾再出现第二根；不能在回溯中凭空复制。
- 团团、重拍器、手机支架、灰色水盆和矮柜的相对位置是固定构图锚点。
- 重拍器状态顺序：第一格蓝光→第二格蓝光→第三格黄光→最后一格红灯锁死→四格短暂红闪→完全熄灭；锁死后不再恢复。

## 5. 角色审核待确认项

以下问题会影响后续角色主参考和资产连续性，需先确认：

1. 团团的年龄感、体型倾向和眼睛颜色。
2. 小林的年龄感觉、是否在角色基准中露脸，以及整体外貌方向。
3. 小林固定服装与鞋袜组合。
4. 整体风格：生活化写实喜剧，还是轻微动画化但保持真实猫科比例。
5. 团团允许的拟人动作边界：仅前爪操作与表情行为，还是允许更明显的主播姿态。

- 团团的剧本身份锚点已经足够明确，可进入角色审核。
- 小林的外观仍有多个高影响未决项，不能直接冻结为正式资产。
- 角色确认前不生成正式 Midjourney 角色提示词，不创建最终资产库，不进入分镜/H3/Seedance 下游。
