- safety_boundary：不生成浸水、窒息、惊吓、强行惩罚或失控泼洒；水盆动作拆成安全局部状态

## 状态变体，不单独新增资产

- 重拍器：第一格蓝、第二格蓝、第三格黄、最后一格红锁死、四格红闪后熄灭。
- 团团：开场局部脏污、回溯观察、冲鱼干、犹豫救场、自主走上毛巾、清洁后包裹。
- 水盆：安全静置、盆沿轻移、水面在盆内晃动、回溯后恢复安全。
- 毛巾：浅黄色浴巾与暖象牙色温毛巾不得互换颜色和用途。
- 鱼干：同一根鱼干反复回到原位；结尾第二根属于新增剧情数量，不是回溯复制。

## 跨资产关系

- ENV_LIVING_ROOM_WEEKEND 固定沙发、矮柜、储物柜、窗户方向和猫可通行地面。
- PROP_REPLAY_DEVICE 固定在矮柜旁地面，团团后爪或前爪能触及。
- PROP_SMARTPHONE_TRIPOD 与 PROP_WATER_BASIN 位于小林脚边附近，高潮时手机支架必须保持稳定。
- ENV_WINDOW_SUN_PATCH 与 PROP_WARM_TOWEL 共同构成团团最终自主靠近的安全区域。
- 团团与所有道具的尺度必须可信；不把重拍器生成成大型科技设备。
- 字幕、倒计时、台词和设备可读文字后期添加，不作为生图资产内容。
