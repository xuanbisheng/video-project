# 《等一下，我先闻闻》角色概念设计审核稿

> 来源：gougou.txt
> 执行规范：character-concept-design skill

## 1. 剧本事实

### 1.1 故事与画面约束

- 故事类型：生活化宠物家庭喜剧，核心是嗅觉误会、短暂戒备与关系修复。
- 主要空间：入户玄关、客厅、厨房之间的连续室内空间。
- 关键时间：傍晚，主人下班回家。
- 主要角色：柯基豆豆、豆豆的主人。
- 关键道具：玄关门垫、钥匙、快递盒、手机、拖鞋、零食罐、鸡肉条、宠物店试吃装狗粮。
- 叙事重点：豆豆通过闻气味判断主人是否异常，最后发现陌生味道来自主人为它购买的宠物食品。
- 表演方式：豆豆的耳朵、尾巴、身体重心和嗅闻动作承担主要叙事；主人主要通过腿部、鞋子、手臂、手掌和少量姿态变化表达情绪。

### 1.2 豆豆的剧本事实

- 物种：柯基。
- 日常习惯：每天傍晚提前趴在玄关门垫上等待主人回家，下巴搁在前爪上，盯着门缝。
- 等待状态：听到脚步声后耳朵竖起，尾巴开始小幅度摆动；钥匙插入锁孔时身体压低、屁股翘高，准备扑迎。
- 回家反应：冲上去绕主人的腿转两圈，尾巴高速摇摆；随后因闻到陌生气味而停住、后退和歪头。
- 调查行为：分别闻主人的左侧裤脚、右侧裤脚、身后气味，再闻拖鞋、快递盒和袖口；全程像小侦探一样保持距离跟随。
- 情绪变化：兴奋迎接 → 警惕怀疑 → 严肃观察 → 犹豫试探 → 发现熟悉气味 → 放松亲近。
- 关系修复：叼起鸡肉条，走到主人腿边坐下，把脑袋搁在主人膝盖上，接受主人轻挠耳朵。
- 结尾状态：闭上眼，尾巴尖仍小幅度摆动；玄关门垫上留有刚才趴卧的痕迹。

### 1.3 主人的剧本事实

- 身份：豆豆的主人。
- 入场可见信息：深色长裤、运动鞋、手提快递盒；故事开头主要看到下半身和手部。
- 行为：把快递盒放下，弯腰脱鞋；拿手机坐在沙发上；伸手摸豆豆的头但被躲开；去厨房打开零食罐；蹲下递鸡肉条；从口袋取出宠物店试吃装狗粮；最后轻轻挠豆豆耳朵。
- 情绪变化：自然回家 → 对豆豆躲避感到困惑和停顿 → 耐心提供食物 → 通过气味误会解除后恢复亲近。
- 未指定信息：年龄、脸部、发型、身形、上衣、鞋款品牌、居家拖鞋样式均未在故事中明确说明。

## 2. 推荐角色概念

### 2.1 豆豆：谨慎而亲人的柯基小侦探

#### 视觉定位（建议）

推荐采用真实比例、短腿长身的威尔士柯基形象，整体偏生活化，不做卡通大头或夸张宠物广告风格。豆豆的喜剧感来自认真过度的调查动作：先热烈迎接，再突然刹车、歪头、分段嗅闻。

- 品种方向：建议采用彭布罗克柯基的紧凑体型；具体亚种需审核后锁定。
- 毛色方向：故事未指定；推荐红白配色，暖红棕背部与白色胸口、口鼻和四脚形成清晰轮廓。
- 脸部：短吻、圆润但真实的头部比例，眼睛有明显观察感；避免过度拟人化眉眼。
- 耳朵：两只三角立耳，能够明确表现竖起、侧转和轻微后压。
- 身体：胸腔较深、腰身厚实、四肢短而有力；允许快速绕腿和突然停步。
- 尾巴：故事要求尾巴有强烈摇摆表演；推荐保留可见的短尾或自然短尾形态，并确认不会被毛色或构图遮住。
- 眼睛颜色：故事未指定；建议深棕色，便于维持真实犬类质感。
- 项圈与配饰：故事未出现固定项圈；建议不增加复杂服饰，若需要项圈，应使用低饱和单色窄项圈并全程固定。

#### 表演语言（建议）

- 等待：趴在门垫上，下巴压在前爪，耳朵朝门缝，身体尽量安静。
- 识别主人：耳朵先竖，尾巴小幅摆，再逐渐抬高臀部准备扑迎。
- 气味异常：冲刺动作突然刹住，鼻尖前伸，身体后移，头向一侧歪。
- 调查：每一次嗅闻都分成靠近、停顿、吸气、退后或转位四个清楚动作；不要用模糊的连续乱动替代。
- 怀疑：坐在沙发扶手上，胸口挺直，眼睛固定盯着主人，拒绝直接蹭头。
- 释然：先迈一步再停，再低头确认食物，最后回到主人腿边坐下。
- 亲近：脑袋放在主人膝盖上，眼睛闭合，尾巴尖保持轻摆，保留一点观察后的余韵。

### 2.2 主人：下班后带回礼物的普通居家主人

#### 视觉定位（建议，待审核）

建议将主人设计为普通都市成年居家男性，避免偶像化、职业制服化或强烈时尚标签。由于原故事大量使用腿部和手部构图，完整全身基准应先定义，后续镜头再按故事需要裁成下半身、半身或手部。

- 年龄感觉：建议 28—35 岁；不是剧本事实，需用户确认。
- 身形：普通成年体型，略瘦或标准体型，能自然完成弯腰、蹲下、坐沙发和盘腿/屈膝等动作。
- 发型与面部：建议自然黑色短发、亲切耐心的普通面貌；可在全身基准露脸，但不让脸部成为故事视觉焦点。
- 上装：建议低饱和灰、深蓝或米白色日常上衣，材质为棉质或薄针织；不得有品牌标志和复杂图案。
- 下装：剧本明确为深色长裤；建议固定为深灰或藏蓝直筒休闲长裤，裤脚不堆叠。
- 鞋子：入门时固定为简洁运动鞋；鞋面颜色建议白灰或黑灰，不能在不同镜头中任意变化。
- 室内鞋：故事提到拖鞋被踢到一边，但款式未指定；建议固定为低调的灰色或米色室内拖鞋。
- 随身物：手机、快递盒、口袋中的试吃装狗粮；这些是剧情道具，不应永久成为角色服装的一部分。

#### 身体语言

- 回家：步伐自然，手提快递盒，身体没有预知豆豆会怀疑自己。
- 困惑：伸手停在豆豆头顶两秒后收回，肩膀略停顿，不做夸张受伤表情。
- 安抚：蹲下时保持低重心，鸡肉条放在可闻但不强迫的位置，手掌动作慢。
- 解释：将试吃装狗粮放在地面，让道具和气味完成信息揭示，不用额外台词解释。
- 修复：豆豆主动靠近后，主人只轻挠耳朵，手腕放松，不突然抱起或抓住犬只。

## 3. 全身角色基准规格

### 3.1 豆豆主参考图

建议制作一张全身多视图角色设定板，包含：

1. 正面自然站立：四脚完整可见，确认短腿、胸口白毛、脸部比例和耳朵高度。
2. 左侧面：确认背线、腹部离地高度、尾巴形态和鼻口轮廓。
3. 背面：确认背部毛色、臀部比例、尾巴根部和后腿站姿。
4. 四分之三视图：确认眼睛、三角耳、鼻尖和胸口毛色连接关系。
5. 中性趴卧姿态：模拟门垫等待，但不加入门垫或其他道具，确保身体比例可重复。

要求：从耳尖到脚爪完整入画，所有视图保持同一毛色、耳朵形状、眼睛颜色和尾巴形态；背景简洁，光线统一，避免用奔跑姿态替代身份基准。

### 3.2 主人主参考图

建议制作一张完整全身多视图设定板，包含：

1. 正面站立：双手自然垂放，显示发型、上衣、深色长裤、运动鞋和整体比例。
2. 左侧面：确认肩背、裤型、鞋底和站立重心。
3. 背面：确认发型后部、上衣下摆、裤腰和鞋后跟。
4. 四分之三视图：确认脸部、手部、衣物轮廓和日常气质。
5. 全身动作小图：提快递盒回家、弯腰脱鞋、蹲下递鸡肉条、坐在沙发上、蹲下放试吃装狗粮；动作图不能产生新的脸型、发型或服装设计。

要求：中性基准图不拿剧情道具、不裁掉头顶或鞋底、不遮挡双手和双脚；后续只出现下半身或手部时，必须从这一全身基准派生。

## 4. 固定锚点与连续性风险

| 角色 | 必须固定 | 可随剧情变化 | 主要风险 |
|---|---|---|---|
| 豆豆 | 柯基短腿长身轮廓、耳朵形状、确认后的毛色、眼睛颜色、尾巴形态 | 耳朵角度、嗅闻姿势、尾巴摆动幅度、迎接/怀疑/释然状态 | 生成成其他犬种；腿变长；尾巴长度或形态跳变；毛色在不同镜头漂移；嗅闻动作变成张嘴攻击或惊吓 |
| 主人 | 深色长裤、确认后的上衣、发型、身形、运动鞋和室内拖鞋的连续关系 | 站立/弯腰/蹲下/坐姿、手持道具、表情和与豆豆的距离 | 只有局部图导致脸型和体型漂移；运动鞋与拖鞋混淆；衣物颜色变化；动作显得强迫或抓取犬只 |

### 道具与场景锚点

- 玄关门垫：豆豆固定等待位置，保留趴卧压痕作为故事开头与结尾的连续性线索。
- 门锁和钥匙：只承担回家声音与动作，不依赖图像模型生成可读文字。
- 快递盒：主人进门时提拿并放在玄关附近，外观保持普通无品牌纸盒。
- 手机：主人坐沙发时使用，屏幕内容不作为生成重点，避免错误文字。
- 鸡肉条：大小、颜色和形态固定，作为豆豆从怀疑转向试探的过渡道具。
- 宠物店试吃装狗粮：建议使用无文字或后期添加包装信息，包装上可保留陌生狗图形作为“陌生味道”的视觉提示。
- 拖鞋：与入门运动鞋明确区分；鞋子变化要通过动作和位置交代，不要让模型自动换鞋。

## 5. 参考资产与生成计划

### 第一阶段：审核前方案

- 豆豆全身多视图主参考，包括中性站立和中性趴卧。
- 主人全身多视图主参考，包含完整鞋袜和服装。
- 豆豆表情/动作表：等待、竖耳、准备扑迎、刹车歪头、分段嗅闻、严肃盯视、释然贴近。
- 主人身体语言表：入门、脱鞋、伸手停顿、蹲下递食、放置试吃装、轻挠耳朵。
- 豆豆与门垫、裤脚、快递盒和鸡肉条的尺度参考。

### 第二阶段：用户审核后生成

- 豆豆：门垫趴卧、扑迎绕腿、闻左裤脚、闻右裤脚、闻主人身后、闻拖鞋、闻快递盒、闻袖口、沙发扶手严肃观察、叼鸡肉条坐到膝边。
- 主人：提盒入门、弯腰脱鞋、沙发坐姿、伸手停顿、厨房蹲姿、手递鸡肉条、放下试吃装狗粮、轻挠豆豆耳朵。
- 之后再从角色基准派生竖屏构图中的下半身、半身和局部镜头。

### 生成提示词草案（审核后执行）

#### 豆豆主参考

正向提示词草案：

> 真实比例的成年威尔士柯基，短腿长身、胸腔厚实、三角立耳、表情聪明谨慎，保持统一的确认后毛色和深棕色眼睛，完整全身，多视图角色设定板，正面、侧面、背面、四分之三视图，四脚和尾巴完整可见，简洁背景，柔和室内光线，自然短毛细节，适合后续图像和视频连续生成。

负面约束草案：

> 不要生成其他犬种，不要长腿，不要改变耳朵形状，不要改变尾巴长度或形态，不要卡通大头，不要攻击姿势、龇牙、惊吓或痛苦表情，不要多肢体、缺失脚爪、文字、Logo、水印、裁掉耳尖或脚爪。

#### 主人主参考

正向提示词草案：

> 普通都市成年居家主人，年龄和性别表达按审核设定，完整全身，多视图角色设定板，正面、侧面、背面、四分之三视图，日常短发与低饱和居家上衣，深色直筒长裤，简洁运动鞋，双手和双脚清楚可见，中性站姿，生活化写实室内光线，简洁背景，人物身份一致。

负面约束草案：

> 不要偶像化模特脸，不要制服、西装、品牌标志或复杂图案，不要年龄和身形漂移，不要改变深色长裤，不要混淆运动鞋与室内拖鞋，不要缺失手指、额外肢体、文字、Logo、水印，不要裁掉头顶或鞋底。

## 6. 待用户审核的选项

1. 豆豆采用红白柯基，还是三色柯基；本稿推荐红白，便于与玄关和室内暖色区分。
2. 豆豆采用彭布罗克体型，尾巴采用可见短尾还是自然长尾；本稿推荐彭布罗克体型与可见短尾，但必须锁定一种形态。
3. 豆豆是否佩戴低饱和单色窄项圈；故事未指定，本稿建议不增加复杂饰品。
4. 主人年龄感觉和性别表达；本稿仅建议普通都市成年男性，不是故事事实。
5. 主人的上衣颜色，以及室内拖鞋的颜色和款式。
6. 整体采用生活化写实喜剧，还是稍微夸张的动画比例；本稿推荐生活化写实。
